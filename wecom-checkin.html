微信内的三条可用路径 直接点「立即跳转」会尝试唤起企业微信打卡页。微信内置浏览器通常会拦截 wxwork:// 私有协议，跳转失败时请用下面这些官方通道。
① 微信插件（最稳，推荐）
微信 → 通讯录 → 我的企业 → 企业名 → 点开任意一条消息，消息页底部有「打开企业微信」按钮，直接唤起客户端，不经过网页、不依赖 scheme。
该按钮由管理员在【我的企业 → 微信插件 → 设置】勾选「在微信插件底部可快捷打开企业微信客户端」后出现。配合企业微信「快捷打卡 / 极速打卡」，打开客户端即自动打卡，无需进打卡页。
② 微信官方唤起页（填自己的链接后实测）
企业微信「成员加入」分享链接在微信里打开后，页面上有「打开企业微信」按钮，微信会弹「即将离开微信，打开其它应用」→ 允许即可唤起客户端。这是腾讯自家域名的白名单通道，但只能到客户端，不能带打卡参数。
获取：管理后台 → 安全与管理 → 管理工具 → 成员加入 → 分享链接。链接有效期与「加入企业须管理员审核」开关有关（7 天 / 365 天）；对已加入成员的显示效果请自行实测。
③ 应用宝链接只到下载页（已实测）
https://a.app.qq.com/o/simple.jsp?pkgname=com.tencent.wework 在微信内打开的是下载引导页，不会拉起已安装的客户端。微下载的「已安装直接打开」需要 App 方在腾讯开放平台配置 android_schema / Applink 协议头，企业微信未对第三方开放，所以这条只能当「未安装时下载」用。
